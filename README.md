# わくわく海釣りアドベンチャー 🚤🌊

海釣り専用ゲーム。ボート釣りと外洋釣り、それぞれ5ステージ、各編1日3回までです。

## GitHub Pages
`index.html`, `style.css`, `game.js` をGitHubリポジトリのルートにアップロードし、Settings → Pages → Deploy from a branch → main/(root)を選択。公開URLをSafariで開きます。音楽は初回タップ以降に再生します。

## ゲーム内容
- ボート：アジ、サバ、マダイ、カサゴ、シロギス、ヒラメ、長靴（0点）、クエ（レア・ボーナス450点）
- 外洋：カジキマグロ、シイラ、エイ、カツオ、キハダマグロ、サワラ、シュモクザメ（0点）、クロマグロ（レア・ボーナス600点）
- レアキャラはステージ3以降、対象餌・ポイントで約8%の確率。釣るまでは「？」表示。
- ステージごとに餌5個。獲得点数が規定値を超えたら次ステージ。失敗すると終了。
- リールの難易度は「やさしい」「ふつう」「チャレンジ」。初期は「やさしい」。BGMオンオフ可。
- 1日3回は各編独立。**プレイ開始時**に1回消費（途中でタイトルに戻っても消費）。端末日付とlocalStorageに依存します。データ削除や別端末利用を防ぐ強制的な保護者制限ではありません。
- ゲーム内の魚の大きさ、出現率、得点はゲーム用の設定です。
- 外部画像や外部ライブラリなし。インターネット不要で動作します。
